## Règles de format .dc.html (obligatoires — échouent en silence)
Squelette exact :
```html
<!doctype html>
<html lang="fr">
<head>
<meta charset="utf-8">
<title>Noyau — Accueil</title>
<script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=...&amp;display=swap">
<style>
body{margin:0}
sc-for,sc-if{display:contents}
/* classes : hover, @keyframes, @media, :focus-visible */
</style>
</helmet>
<div style="... root fluide ...">…</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":1440,"height":6000},"accent":{"editor":"color","default":"#00AEEF","options":["#00AEEF","#7C5CFF","#F5B700"]}}'>
class Component extends DCLogic {
  constructor(props){ super(props); this.state = { pilier: 0 }; }
  renderVals() { return { ... }; }
}
</script>
</body>
</html>
```
- Ligne `<script src="./support.js"></script>` EXACTE. Fermer tous les éléments non-void ; guillemets sur tous les attributs ; `&amp;` dans les URL Google Fonts.
- PAGE fluide : root sans largeur px ; conteneurs `max-width` + padding latéral ; grilles `repeat(auto-fit, minmax(min(280px, 100%), 1fr))` ; hauteurs px/rem (jamais `%`, pas de `vh`) ; nav repliée sur mobile (@media). Très grands titres : `clamp()` vérifié pour tenir à 1440 et 390 px de large (longueur des mots !), `overflow-wrap:anywhere` en secours.
- `{{trou}}` = lecture à points UNIQUEMENT, jamais d'expression. Tout calculer dans `renderVals()`.
- Événements : `onClick="{{ pick }}"`, `onInput="{{ setX }}"`, `onChange` pour select/checkbox ; handler par élément via map dans renderVals ; `onSubmit` → `e.preventDefault()`.
- `<sc-if value="{{ cond }}" hint-placeholder-val="{{ true }}">` (pas de else : deux drapeaux) ; `<sc-for list="{{ items }}" as="item" hint-placeholder-count="3">`. Jamais de `<sc-for>`/`<sc-if>` directement dans `<select>`, `<table>`, `<tr>`, `<ul>`, `<ol>` (structure en div, ou options écrites en dur).
- Valeurs dynamiques : `src="{{ x.img }}"`, `style="{{ x.style }}"`, `value="{{ x }}"` OK ; PAS de trou dans `class` (utiliser `style` ou deux éléments sous sc-if).
- Styles variables : chaîne pré-calculée liée à `style` ; tokens statiques inline en dur.
- CSS dans `<helmet><style>` : hover, @keyframes (révélations, marquee, glow, typewriter…), @media, `:focus-visible`. `url()` d'image uniquement dans helmet ; sinon `<img>` + object-fit.
- Aucun réseau sauf Google Fonts css2 et `assets/…`. Pas d'`<iframe>`, `<object>`, `<embed>`, `innerHTML`, `appendChild`, `window.X`, keydown global, imports. Un éventuel `setInterval`/`setTimeout` (ex. démo ATOM qui « tape ») doit être créé dans `componentDidMount` ou au clic et nettoyé dans `componentWillUnmount`. JS classique.
- Icônes : SVG inline au trait, jamais d'emoji. Boutons icône seule avec `aria-label`. Vrais contrôles. Cibles ≥ 44 px. Contraste ≥ 4,5:1.
- `data-props` : `$preview` + 1 à 3 réglages, TOUJOURS au format descripteur `{"editor":…,"default":…}`.
- Pas d'Inter, Roboto, Arial, Fraunces. Pas de dégradés « IA » génériques violets-bleus en fond partout, ni cartes à bordure gauche colorée, ni emoji, ni faux logos clients.
- Interactivité réelle et riche sur chaque page (évaluée) : survols soignés, animations d'entrée, transitions, états sélectionnés, compteurs.
